## 🚀 Overview

This repository hosts the personal portfolio website of **Anil Kumar**, a Publisher Solution Specialist with 7+ years of experience across ad operations, campaign management, programmatic advertising, and search monetization at **Airfind** and **Taboola**.

The website is engineered with a **custom dark glassmorphism design system**, animated metrics telemetry, interactive skills matrix, and multi-specialization resume downloads.

---

## ⚡ Key Highlights & Features

- 💎 **Modern Dark Luxury Glassmorphism:** Custom CSS design system with fluid typography, responsive layout, and neon brand accents.
- 🎯 **Interactive AdTech Telemetry:** Animated metric counters showcasing **+30% Revenue Growth**, **1,000+ Resolved Deployment Tickets**, and **99% CSAT**.
- ⏱️ **Career Timeline:** Comprehensive breakdown of roles at Airfind, Taboola (Senior Rep & Rep), Verifacts, and AuthBridge.
- 🛠️ **Categorized Skills Matrix:** Interactive category filtering across AdTech, Attribution & Tracking, Code & Web, Analytics & BI, and CRM/Workflow.
- 📄 **Multi-Resume Hub:** Direct preview and 1-click download options for:
  - *Master Resume* (`Anil_Kumar_Resume.pdf`)
  - *Ad Operations Specialist Resume*
  - *Programmatic Ads Specialist Resume*
  - *Campaign Manager Resume*
- 📱 **100% Responsive & SEO Optimized:** Semantic HTML5, OpenGraph tags, JSON-LD structured data for search engines.

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, Modern CSS3 (Custom Properties, Glassmorphism, Grid/Flexbox), Vanilla JavaScript (ES6+)
- **Typography:** Plus Jakarta Sans & JetBrains Mono (Google Fonts)
- **Icons:** Font Awesome 6.5.1
- **Hosting:** GitHub Pages
